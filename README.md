

Un programme Java en ligne de commande (CLI) interactif permettant de réaliser des opérations mathématiques de base et des statistiques simples à l'aide d'un menu textuel.

##  Fonctionnalités

- **Addition** : Calcule la somme de deux nombres entiers.
- **Multiplication** : Calcule le produit de deux nombres entiers.
- **Moyenne** : Calcule la moyenne arithmétique d'une série de nombres (utilise les arguments variables `varargs`).
- **Maximum** : Identifie la valeur maximale au sein d'une liste d'entiers fournis par l'utilisateur.

##  Concepts Java utilisés

- **Boucle interactive** (`do-while`) et structures conditionnelles (`if / else if`).
- **Saisie utilisateur** via la classe `java.util.Scanner`.
- **Méthodes statiques** pour l'encapsulation de la logique de calcul.
- **Varargs (`int...`) et Tableaux** pour la gestion dynamique des paramètres.
